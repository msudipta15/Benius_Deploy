MODE: READ-ONLY DATABASE INSPECTION

I approve read-only database identity and metadata queries only.

OBJECTIVE:
Confirm that the database used by the running Development API is the same intended Development PostgreSQL database targeted by Replit's migration/database tools.

STEP 1 — CONNECTION IDENTITY

Using the Development API's configured DATABASE_URL, establish a read-only database connection.

Separately inspect the Replit-managed Development database connection.

Compare safe database identity information, such as:
- Database name
- PostgreSQL server address identity, without credentials

If both connections cannot be positively identified as the same intended Development database, STOP.

Inspect the actual migration tracking table to determine whether migration 021 has already been applied.

Use SELECT and PostgreSQL metadata queries only.
